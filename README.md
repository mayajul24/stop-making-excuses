# סתמי ותזדייני

אפליקציית עידוד שבועית לדייטים. משימה אחת בשבוע, ארבע רמות קושי, רצף, XP, ומסלול
בסגנון דואולינגו. נבנתה למשתמשת אחת ("היא") ולמאמנת אחת ("מאיה").

כרגע זה **פרוטוטייפ frontend עם נתוני mock** — אין עדיין backend, התחברות, או
התראות. כל הנתונים מגיעים מקובץ אחד, `src/data/mock.ts`.

## הרצה מקומית

```bash
npm install
npm run dev
```

הדף עולה ב-http://localhost:5178

## מבנה

- `src/lib/game.ts` — כל חוקי המשחק: ארבע הרמות, עלויות ה-Courage, ה-XP, שמות
  הרמות וה-Achievements. **המספרים כאן סופיים** — אל תשני אותם בלי סיבה.
- `src/lib/voice.ts` — כל הטקסטים שמשתנים לפי מצב (באנרים, מה שהכלבה אומרת).
  אנגלית לפאנצ'ליינים, עברית להסברים.
- `src/lib/path.ts` — הופך את ההיסטוריה לצמתים במסלול.
- `src/data/mock.ts` — הנתונים המזויפים. זו הנקודה היחידה שצריך להחליף כדי לחבר
  backend אמיתי.
- `src/components/` — הכלבה (4 מצבי רוח), המסלול, ה-Courage.
- `src/styles/tokens.css` — כל הצבעים והגדלים.

## מכניקה

| רמה | XP | Courage |
|---|---|---|
| 🟢 Easy — לפתוח אפליקציה ולעשות לייק | +5 | 1 |
| 🟡 Medium — לשלוח הודעה | +15 | 1 |
| 🔴 Hard — להציע דייט | +30 | 2 |
| 💀 Nightmare — לצאת לדייט | +50 | 3 |

- **Courage** — מקסימום 3, מתחדש ב-1 בכל מעבר שבוע. לא מתאפס.
- **Freeze** — מגן על הרצף בלי לבצע אתגר. מתחדש כל שבועיים, מקסימום 4.
- **Coward mode** — אף פעם לא "נכשלת": בוחר אוטומטית Medium.
- **רמות** — לפי מספר אתגרים שהושלמו, לא לפי XP גולמי.

## מה עדיין לא בנוי

מסך המשימה עם השלבים, מסך Out of Courage, ההישגים, לוח השנה של הרצף, הפרסים,
ומצב מאיה. וכן: backend אמיתי, התחברות, והתראות push.
